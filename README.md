# 단골 지키미 — 단골 이탈 알림 + 재방문 쿠폰 데모

**"놓치고 있던 돈을 찾아주는 시스템" 시리즈 10종 중 2번** (다른 9개와 연결됩니다)

단골이 "조용히" 떠납니다. 항의하지도, 이유를 말하지도 않고 그냥 안 옵니다. 그동안 사장님은 "내가 뭘 잘못했나" 자책하셨죠. 잘못하신 게 아니에요. 바쁘셨을 뿐입니다.

이제는 **단골 관리를 시스템이 알아서 챙겨줘요**. 걱정 마세요. 방문 기록을 적어 두기만 하면, 안 오시는 단골을 시스템이 먼저 찾아내고, 재방문 쿠폰으로 안부를 전하고, 몇 명이 돌아왔는지 숫자로 보여줍니다.

## 왜 만들었는가

- **날짜**: 2026-10-12
- **이유**: 동네 사장님들은 떠나는 단골을 보며 "내가 뭘 잘못했나" 자책합니다. 바빠서 못 챙긴 것뿐인데 말이죠. 자책 대신 안심을 주고 싶었습니다.
- **누구를 위해**: 청소·미용실·네일샵·이사·용달, 동네에서 장사하는 사장님들. 개발자가 아니라 돈을 쓰는 사장님이 고객입니다.

## 버전 히스토리

- **2026-10-12**: 감정 설계를 도입한 날 — "짜증 모먼트" 오프닝, "단골 관리를 시스템이 알아서 챙겨줘요" 프레이밍, 쓰나미 트리거("김○○님이 돌아왔어요… 사장님이 건넨 안부 덕분이에요") 추가
- **2026-10-12**: 업종별 특화 — 청소업체/미용실·네일샵/이사·용달 프리셋 (이탈 기준·쿠폰 예시 변경)
- **2026-10-12**: 심리 설계 — 오늘 브리핑(도파민), 벤치마크 비교, 레벨업, 데이터 락인, 가격 심리(월 3만원 + ROI)
- **2026-10-12**: 바이럴 메커니즘 — 추천 리워드, 경쟁 FOMO, 월간 성공 리포트, 성장 시뮬레이터
- **2026-10-12**: 입소문 필연성 — 매장용 배지(인쇄), 단톡방 공유 이미지 자동 생성, 익명 이웃 자극, 추천 보상(둘 다 1개월 무료 + 첫 달 매출 1% 리워드)
- **2026-10-12**: 레거시 철학 — "우리의 약속" 화면 ("높은 가치는 느끼는 사람들에게", "이 데이터는 10년 후에도 사장님의 것입니다", "가게 이어받기: 아버지의 단골 명단이 아들에게")
- **2026-10-12**: 인간에 대한 약속 — 7가지 가치 원칙 (정직한 데모 라벨, 다크패턴 금지, CSV 데이터 가져가기, "시스템 덕분"이 아닌 "사장님 덕분", 사장님 속도에 맞추기)
- **2026-10-12**: 존엄(Dignity) — 돈을 세는 대신 사람을 셉니다 ("이번 달 N가족이 사장님을 다시 찾았어요", "이번 달 사장님이 도운 가정: N곳", 직업의 의미, 사명 선언문 "우리는 사장님의 일을 세상이 알아주게 만듭니다", "당신의 일이 소중합니다")

## 타겟 고객

- **동네 사장님 (청소·미용실·이사·인테리어 업체)**: 개발자가 아닌, 돈을 쓰는 사장님이 고객입니다
- "단골이 왜 안 오는지 모르겠다"는 사장님 — 이유를 시스템이 먼저 알려줍니다
- 문자 마케팅은 하고 싶은데 "누구에게 보내야 할지" 모르는 사장님
- **타겟 단가: 초기 구축 100~200만원 + 월 관리비 5~10만원** (쿠폰 발송 대행 포함 시 상향)

## 실행 방법

```bash
bash run.sh
```

브라우저에서 접속 (첫 화면은 "짜증 모먼트" 오프닝 → **5분 안에 직접 써보세요** 버튼):

- **오프닝**: http://localhost:5008/opening — "매달 오던 김○○님이 4개월째 안 옵니다. 아무도 몰랐습니다." 숫자로 보여주는 사장님의 아픈 순간
- **어떤 가게세요?**: http://localhost:5008/start — 청소업체 / 미용실·네일샵 / 이사·용달 선택 (업종별 기준·쿠폰 예시 변경)
- **오늘의 가게**: http://localhost:5008 — "챙겨주면 ○○만원을 지킬 수 있어요" + 가치 계산기 "이걸 쓰면 월 ○○만원 벌어요"
- **단골 명단**: http://localhost:5008/customers — 고객 등록 · 방문 기록 추가 (날짜, 금액)
- **떠나가는 단골**: http://localhost:5008/risk — 안 온 지 오래된 순으로 보여주고, 체크해서 쿠폰 발송 (핵심 기능까지 3클릭)
- **쿠폰 보내기**: http://localhost:5008/coupons/new — 대상 선택 → 쿠폰 작성(업종별 예시 버튼) → 즉시 발송/예약
- **효과 보기**: http://localhost:5008/effect — "쿠폰 받고 돌아온 단골 ○명 (○%), 되찾은 매출 ○○만원"

(Flask가 없으면 자동으로 설치합니다. 포트 5008이 사용 중이면 자동으로 다음 빈 포트로 켜지고, 실행 화면에 실제 주소를 알려줍니다. 업종 선택 시 해당 업종에 맞는 예시 단골 36명 + 방문 기록이 자동으로 채워집니다. 종료는 터미널에서 `Ctrl+C`)

## 핵심 어필 포인트

1. **짜증 모먼트로 시작**: "매달 오던 김○○님이 4개월째 안 옵니다. 아무도 몰랐습니다." — 사장님의 실제 하루를 숫자로 재현하고, "사장님 잘못이 아니에요"로 안심시킵니다
2. **감정적 해방**: "단골 관리를 시스템이 알아서 챙겨줘요" — '자동화'가 아니라 '편하게·안심·걱정 마세요'의 톤. 자책하던 사장님에게 주는 안심감
3. **업종별 특화**: 청소업체(정기 2주/월1회 기준 21일·45일) · 미용실·네일샵(커트 4주·염색 6주·네일 3주 기준 45일·90일) · 이사·용달(소개 유도형 180일·365일). 업종별 쿠폰 예시 버튼 포함
4. **가치 계산기**: "이걸 쓰면 월 ○○만원 벌어요" — 이탈 위험 단골의 월평균 매출로 계산, 쿠폰으로 실제 되찾은 돈은 더 크게 표시
5. **숫자로 보여주는 돈**: "떠나가는 중 N명"이 아니라 "챙겨주면 ○○만원을 지킬 수 있어요" — 사장님의 지갑을 직접 건드립니다
6. **손댈 것 없음**: 방문 기록만 적어 두면 나머지는 시스템이 챙깁니다. 엑셀 정리 같은 수고가 없습니다
7. **3단계 쿠폰 발송**: 대상 고르기 → 쿠폰 쓰기(미리보기 포함) → 바로 보내기/예약. 문자 발송 업체 연동만 하면 실전 투입 가능
8. **효과를 돈으로 증명**: "쿠폰 받고 돌아온 단골 ○명, 되찾은 매출 ○○만원" — 다음 달 관리비를 받는 근거가 됩니다
9. **사장님 말로 된 화면**: "churn", "세그먼트" 같은 개발자 용어 제로. "떠나가는 단골", "돌아올 가능성"으로만 말합니다. 60대 사장님도 쓸 수 있게 큰 버튼·큰 글씨, 모바일 375px 기준 설계
10. **10종 패키지**: "놓치고 있던 돈을 찾아주는 시스템" 10종 중 2번 — 다른 9개와 연결됩니다

## 사장님 심리 설계

기능이 아니라 심리로 붙잡습니다:

1. **짜증 모먼트 오프닝**: 첫 화면에서 "매달 오던 김○○님이 4개월째 안 옵니다. 아무도 몰랐습니다." — 사장님의 실제 하루를 숫자로 재현하고 짜증을 느끼게 한 뒤, "사장님 잘못이 아니에요"로 안심시킵니다
2. **오늘 브리핑 (도파민 대시보드)**: "돌아온 단골 3명, 이번 주 되찾은 매출 28만원" — 매일 아침 확인하고 싶은 숫자
3. **벤치마크 비교**: "우리 동네 미용실 재방문율은 평균 62%, 사장님은 41%" — 익명 통계로 경쟁심을 자극하되, 톤은 따뜻하게 ("금방 따라잡아요 💪")
4. **레벨업**: "단골 관리 레벨 3 달성! 옆 가게 평균은 레벨 2입니다" — 방문 기록·쿠폰 발송할수록 오르는 레벨과 다음 레벨까지의 진행률
5. **데이터 락인**: "누적 고객 데이터 N건, 이걸 버리시겠어요?" — 쌓인 기록이 곧 돈이라는 메시지
6. **가격 심리**: "월 3만원으로 떠나는 단골을 붙잡으세요" + ROI 계산기 ("지금 지킬 수 있는 월 74만원, 투자금의 24배")

## 바이럴 메커니즘 (지수 성장 엔진)

쓰는 사장님이 옆 가게 사장님을 데려옵니다:

1. **추천 리워드**: 설정 화면에서 "옆 가게 사장님께 소개하면 둘 다 1개월 무료" — 내 소개 링크 생성 시뮬레이션 + 복사 버튼
2. **경쟁 FOMO**: 대시보드에 "같은 동네 미용실 128곳이 단골 관리를 시스템에 맡겼습니다" — 나만 안 쓰면 뒤처지는 느낌
3. **성공 사례 자동 생성**: 효과 측정 화면 상단에 "○월 성공 리포트" 자동 생성 — "이번 달 돌아온 단골 ○명, 되찾은 매출 ○○만원" + "동네 평균 재방문율 대비 +○%p"
4. **성장 시뮬레이터**: 설정 화면에서 슬라이더로 월 소개율(0~30%) 조절 → 복리로 계산된 1년 후 가게 수 그래프 ("1년 후 약 N곳이 함께합니다")

## 기술

- Python Flask + SQLite (`customers.db` 자동 생성, 첫 실행 시 예시 데이터 자동 입력)
- 외부 API·유료 서비스 없음 (쿠폰 발송은 시뮬레이션 — 실제 문자 발송 시 문자 API 연동 필요)
- 한국어 UI, 모바일 반응형 (폰에서 쓰는 사장님 기준 설계)
- 모든 오류는 사장님 말로 안내 (traceback 노출 없음)
